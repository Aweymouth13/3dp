ANKER PRIME CHARGING STATION A91B2 WALL MOUNT — V1

Exact target device:
Anker Prime Charging Station (8-in-1, 240W), model A91B2
Official station dimensions used: 3.07 x 5.43 x 0.71 in = 78.0 x 137.9 x 18.0 mm.

Orientation:
- Long direction vertical
- Display / AC outlets face outward
- USB-C short edge points downward
- Side edges mostly open for USB-A access

Included:
- anker_a91b2_wall_mount.stl  -> ready for slicer
- anker_a91b2_wall_mount.scad -> editable source, free OpenSCAD

Fit:
- 0.8 mm nominal total clearance
- Four short corner clips retain the station
- Center of bottom edge is intentionally open for USB-C cables
- Two countersunk ~4.2 mm screw holes are above/below the device footprint

Print suggestion:
- PETG preferred, PLA+ fine for normal indoor use
- 0.20 mm layers
- 4 walls/perimeters
- 25-35% infill
- Print with flat wall plate on build plate
- No supports expected

Mounting:
Use wall fasteners appropriate for the wall material. The charger itself is ~230 g, but attached power/USB cables can add leverage, so don't rely on weak drywall screws alone.

If the fit is too tight/loose, edit `clearance` in the .scad file and re-export. OpenSCAD is free.
